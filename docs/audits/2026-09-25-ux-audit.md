## Rules every fix follows

1. One word per concept — a status has one label, one colour, one casing, everywhere.
2. Verbs first — every page answers "what needs me now?" before charts or history.
3. Plain words — jargon (NDR, AWB, manifest, A+) moves to tooltips.
4. Cut copy in half — if a button needs a sentence, the button is wrong.
5. Dangerous things look dangerous — delete / impersonate / cancel never sit as unlabeled icons.

Priority: **P0** wrong decisions or real confusion today · **P1** slows people daily · **P2** polish.
